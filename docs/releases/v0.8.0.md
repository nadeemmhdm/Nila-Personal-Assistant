# Nila 0.8.0 — A Little More Personal

- New responsive About/landing page with the lotus logo, a clearly fictional origin story, setup steps, model guidance, privacy boundaries, all release notes, full documentation and searchable error help.
- Nila remembers its chosen birthday, March 2, 2026, as application identity. On March 2, the first successful normal chat each year asks the local model to mention its birthday; the laptop's local date is used. No unattended cloud message or closed-app notification is sent.
- Fix the installed Web logo route. The binary smoke test now requests the real image and About page through the packaged server.
- Remove canned greeting answers. The selected local model receives the actual greeting, with instructions to match its wording, language and time of day. Standalone greetings omit unrelated history and avoid web retrieval.
- Web, CLI (including interactive /model) and Telegram now check installed models, download missing selections once and load before changing the saved selection. Failed activation retains the previous model. Existing model names and mappings remain supported.
- Composer search, thinking and model menus show meaningful option descriptions and support keyboard/outside-click dismissal.
- Speech input checks local language support, installs missing supported browser packs and falls back from unsupported English locales to en-US. Windows local microphone recognition is available as an explicit alternative. Unsupported languages remain clearly reported; audio is never silently sent to a cloud recognizer.
- Read-aloud buttons become Stop during playback and return when playback ends. Remove the separate speech-stop button from the composer.
- Keep attached text/PDF content in local requests with web mode selected, show filenames on sent messages and support file-only sends. Attached private answers are not saved as public web knowledge.

Model inference and native voice quality still depend on installed models, browser/Windows language packs and hardware. Automated tests mock speech/Ollama; test your actual microphone and voices after updating.
