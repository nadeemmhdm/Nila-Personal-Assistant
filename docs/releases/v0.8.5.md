# Nila v0.8.5 — Clearer Connections

This update polishes the connected workspace and fixes several remaining interaction gaps.

- Gmail time windows: `@Gmail read emails from the last 10 minutes`, hours or days (up to 31 days), plus `@Gmail unread emails`. Reads remain bounded to five inbox previews; only connected accounts can be read.
- Local service marks for Gmail, Drive, Docs, Sheets, Classroom, YouTube and Meet, with account identity and accurate read/write permission badges.
- Connected-service autocomplete no longer appears while typing a normal email address.
- YouTube previews support reordered watch query parameters, mobile links, Shorts and embed URLs. Players still load only after a click.
- Minimal greeting-specific model instructions omit birthday/calendar context except for the actual annual reminder. Birthday questions retain Nila’s March 2, 2026 date.
- Actionable OAuth hosting error when a host returns a browser-only HTML page rather than the API.

Existing explicit Google writes, persistent multiple skills, Telegram documents/photos and sticker replies remain included. Photos require a vision-capable local model. Google tokens/results are not sent to Gemini or public search. All Google services remain disabled on Telegram.

## Install

Run `nila update` and restart Nila.

The separate PHP OAuth v0.8.3 ZIP remains compatible, including root index.php and setup instructions. InfinityFree free hosting blocks inbound app/API calls; use an API-capable PHP host. No PHP website source is published in the repository.

## Verification

170 local Python tests, TypeScript/Vite production build, and Chromium checks for connected mentions, Google reference/token isolation and click-only video playback passed. Provider responses were simulated; live Google OAuth and Telegram account delivery were not exercised.
