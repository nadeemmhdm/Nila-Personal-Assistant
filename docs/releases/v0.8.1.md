# Nila 0.8.1 — Your Domain, Your Connection

- Enter an OAuth website domain in Web or CLI; Nila automatically adds HTTPS and the PHP endpoint. Folder URLs and explicit HTTPS PHP endpoints remain supported.
- Save & connect checks the private OAuth server and its configured callback. Add `nila google setup --domain ...` and `nila google check`.
- Remove PHP website source and its server tests from the current repository. Deliver them in a separate private ZIP with English/Malayalam deployment and Google OAuth steps; the local Nila client remains in the repository.
- Fix the landing workflow's missing-Pages handling: always build a downloadable static website, check Pages configuration, and deploy only when GitHub Actions is selected as the Pages source. Disabled Pages now produces an explicit setup notice rather than failing in configure-pages.

One-time repository administration is still required to enable GitHub Pages. The separate PHP website requires your own HTTPS host and Google Cloud credentials. Neither service is automatically deployed by entering an unconfigured domain.

Previously published commits/tags remain historical snapshots; removing files from the current branch does not rewrite repository history.
