# Nila v0.8.4 — Connected Workspace

Includes all [v0.8.3 workspace features](v0.8.3.md), plus direct @Drive and @Meet read routing. This patch ensures the latest connected-service fixes are included in the downloadable release binaries.

- Connected-account mentions and one-time read/read-write Google sign-in bundles.
- Explicit Google writes, disabled by default until locally enabled. Regeneration never repeats writes.
- Persistent multiple skills, click-to-play YouTube and Telegram attachments/sticker replies.
- Greeting birthday context fix and refined Web controls.

Run `nila update`. Upload the separate v0.8.3 PHP OAuth ZIP to an API-capable PHP host. InfinityFree free hosting cannot serve the broker API. Google/Telegram live account access requires your configured credentials; local verification used simulated provider responses.
