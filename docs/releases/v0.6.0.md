# Nila 0.6.0 — Personal Workspace

## Updates

- Updates now follow stable GitHub Releases. Managed Windows updates download a prebuilt executable, verify its GitHub SHA-256 digest, smoke-test its version, and switch installations under the existing exclusive lock. Failed checks retain the current installation. No local Python/Node build is needed for subsequent updates.
- `nila upadte`, `nila updatw` and `nila udpate` are accepted as aliases of `nila update`.
- Publication runs only after Windows and Linux tests and binary builds succeed. Existing version releases are never overwritten.

## Chat and interface

- Sources opens a detail panel and closes on a second click, Escape, or clicking outside. Source URLs are no longer appended as a separate generated footer.
- Copy, regeneration, voting and read-aloud controls sit below the message content. Sidebar temporary-chat and preference checkbox layouts are corrected.
- Attached files stay visible when reopening chats, can be removed, and can be sent without typing a question. Nila summarizes file-only submissions; extracted text is supplied to the local model.
- Conversation names use the first completed assistant answer. Developer questions have a direct Nadeem/GitHub response.
- Paired underline markers render around nested emphasis without exposing raw formatting. Code operators remain unchanged.

## Personal workspace

- Models dashboard lists installed Ollama models and supports refresh, download, and load-and-use. Selection changes only after successful model loading.
- Ten selectable local instruction skills, plus Markdown import, inspection, disabling and deletion. CLI: `nila skills list`, `nila skills add file.md`, `nila skills use ID`, `nila skills off ID`.
- Goals, tone and preferred answer detail guide relevant local replies. Automatic personal-fact extraction still respects memory review and sensitive-data exclusions.
- Successful web-assisted answers save encrypted, dated evidence for later offline use; inspect and delete it in Workspace → Knowledge. Learning Lab continues to save reviewed lessons when enabled. These are retrieval notes, not model-weight training or verified truth.
- Quick/deep search skips ordinary stable questions. Explicit search requests and freshness keywords trigger retrieval; this is a keyword heuristic, not a guarantee that a model knows an answer. Use “search …” to force lookup.
- Skills and cached evidence are included in encrypted backups. Older backups remain importable.

## Telegram and voice

- `/search off|quick|deep`, `/think low|medium|high`, `/status` and `/new` controls.
- Repeated typing indicator, animated status and elapsed time while generating; Sources button opens reference details. Only the configured private owner can use the bot.
- Web read-aloud uses installed local system voices. Microphone input requires a browser with on-device speech recognition and an installed language pack. Unsupported browsers show an inline explanation; audio is not silently routed to a cloud recognizer. Stop microphone and Stop speech controls are provided.

## Privacy and limits

Gemini receives only explicitly consented Learning Lab topic exchanges, never ordinary chat history, profile, attachments, custom skills or personal memory. Telegram uses Telegram's network and requires Nila running on the laptop. Search queries go to public search providers when used. No publisher code-signing certificate is bundled; Windows application-control decisions remain in force.
