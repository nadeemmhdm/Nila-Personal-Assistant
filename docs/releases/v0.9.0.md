# Nila v0.9.0 — Local Engine Choice

- Keep Ollama or select the experimental managed llama.cpp backend from **Workspace → Engine & downloads** or `nila engine llama.cpp --profile fast`.
- Fast, Medium, Smart and Vision GGUF profiles; verified downloads reuse existing files. Automatic CPU runtime setup supports Windows/Linux x64.
- Chat and Learning Lab now queue local inference rather than immediately failing when busy. Navigation stays accessible while responses stream; old responses do not replace newly opened chats.
- Optional local Whisper multilingual STT and Piper English TTS pack, with isolated dependencies, microphone recording and Play/Stop controls. Install through the workspace or `nila components speech`.
- `nila components vision` installs/selects a vision model for the active backend. Existing Telegram photo analysis uses that model. Text documents use the existing language model; scanned PDFs still require OCR.
- Added PHP hosting guidance for alwaysdata. The PHP broker remains a separate ZIP and is not published in this repository.

## Update

Run `nila update`, then restart Nila. Choose **Workspace → Engine & downloads** for optional components. Downloads require internet once; local inference and installed speech models work offline. Gemini tutoring, Google services, Telegram delivery and public web search still require internet.

## Limits and validation

175 Python tests and the TypeScript/Vite production build passed locally. Provider adapters, download integrity, queue cancellation and audio cleanup are tested with simulated responses. Full llama.cpp/model and speech-pack installation could not be completed in the development environment because the external runtime request timed out; hardware compatibility, microphone recognition and live provider accounts are not claimed verified. Start with Fast on a low-memory laptop. See `docs/LOCAL_ENGINES.md` for component licenses, platform support and troubleshooting.
