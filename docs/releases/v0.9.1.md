# Nila v0.9.1 — Runtime Recovery

This patch improves recovery around optional local components.

- Failed or cancelled llama.cpp startup cleans up the process created by that attempt, allowing a fresh retry. Existing processes are not killed by a failed probe.
- Process shutdown waits run outside the UI event loop, keeping navigation responsive during engine switching.
- Returning to Ollama preserves the latest selected Ollama model instead of restoring an outdated saved name.
- A cached vision profile with a missing projector goes through installation again.
- Speech setup skips Python candidates that time out and continues looking for a usable interpreter.

## Update

Run `nila update`, then restart Nila. Existing settings and conversations remain in place.

## Verification

Regression tests cover failed/cancelled process cleanup, preservation of existing processes and current Ollama selection. These use simulated processes. Full model downloads, microphone quality and target CPU compatibility remain outside this verification; llama.cpp remains experimental.
