# Nila v0.8.3 — Connected Workspace

- Connected-service @mention picker with account labels and colored icons; ordinary explicit read prompts remain supported.
- One Google sign-in bundle for seven services, with read-only and read/write choices. Confirm the account locally.
- Persistent local write permission, off by default. Gmail send, Docs append, Sheets update, app-created Drive document creation, Classroom course creation, YouTube comment, Meet space creation.
- User-authored details only; no guessed recipient, model-generated actions, destructive operations or automatic retries. Regeneration never repeats writes.
- Click-to-play privacy-enhanced YouTube embeds. No video player contact before clicking.
- Multiple encrypted Markdown skills remain enabled until individually disabled.
- Owner-only Telegram documents/photos up to 5 MB; vision capability checks and sticker emoji replies with sticker echo. Animated stickers use emoji context, not animation analysis.
- Refined composer, connected-account controls and skill cards.
- Birthday information is supplied only when asked or for the actual once-yearly birthday reminder, preventing irrelevant birthday context in greetings.
- Explicit Telegram documents reach local analysis even when personal-memory sharing is off.

## Usage

Connect all · read & write, confirm your account, then enable Allow explicit chat writes once. Read-only remains available separately.

```text
@Gmail read my latest email
@Docs summarize https://docs.google.com/document/d/YOUR_ID/edit
@YouTube show my channel
@Gmail send to person@example.com subject "Hello" body "Your exact message"
@Docs append "Your exact text" to id: YOUR_ID
@Meet create a meeting link
@Sheets update {"id":"YOUR_ID","range":"A1:B1","values":[["Name",42]]}
```

Incomplete writes ask for details; arbitrary natural-language edits are not supported. Google API scopes, quotas, Workspace account eligibility and administrator policies still apply. Tokens/results remain excluded from Gemini and public search. Google access stays off on Telegram and in temporary chats. Text-only Qwen3 profiles cannot analyze photos; select a vision-capable Ollama model.

PHP source remains a separate ZIP outside GitHub. It includes root index.php and hosting instructions. InfinityFree free hosting blocks inbound app/API requests; this broker requires an API-capable PHP host and does not bypass host protections. Live Google OAuth and Telegram delivery require your own configured accounts; local tests simulated provider responses.
