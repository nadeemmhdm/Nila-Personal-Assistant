SMALL COMPANION. MANY POSSIBILITIES.

One assistant.
More ways to be you.

01 / CONVERSATION

Pick up where you left off.

Web, CLI and private Telegram chat. Continue a conversation, edit a prompt, regenerate with guidance, copy answers and give feedback. Temporary chats keep conversation data in memory while the session runs.

02 / MEMORY

A little context goes a long way.

Personal facts, accepted Learning Lab lessons and saved web references stay encrypted locally. Review suggestions, inspect sources and forget entries. Relevant saved knowledge can support offline answers.

03 / RESEARCH

Curiosity, with sources.

Choose Quick, Deep or Off. Nila looks up public questions, compares snippets and links to sources. Attached files stay local and take priority. Search providers need internet and can be unavailable.

04 / LEARNING LAB

A study partner for your model.

Gemini asks questions and reviews local answers on a topic you choose. Accepted lessons become reference notes. Set a duration or stop any time. This is saved knowledge, not model-weight training.

05 / WORKSPACE

Bring your own context.

Attach text or text-based PDFs, organize projects, select one of ten built-in skills or import a Markdown skill. Skill instructions do not execute code. Scanned PDFs need external OCR; image vision is not included.

06 / VOICE

Type it. Say it. Hear it.

Use supported browser speech packs or Windows local recognition. Play and stop answers from the same button. Supported languages depend on the installed voice and recognizer. Audio is not silently sent to a cloud service.

THE NILA ORIGIN STORY · JUST FOR FUN

In a tiny corner of a laptop, a curious blue spark kept asking one question: “What if technology felt a little more personal?”

Nadeem gave that spark a name — Nila — and a special day: March 2, 2026. In our little story, the spark unfolded into a lotus. Each petal carried a possibility: a useful answer, a remembered detail, a new idea.

Nila didn’t arrive knowing everything. She learned to ask better questions, keep notes and make room for the person on the other side of the screen. Her favourite place wasn’t a distant cloud. It was right there, beside your next thought.

That’s the playful story. In real life, Nila is an open-source assistant application developed by Nadeem, powered by Ollama models. March 2 is its commemorative birthday, not a claim about the first public release or model training date. On that day, a normal successful chat prompts one birthday mention per year, using the laptop’s local date. No background message is sent while Nila is closed.

CLEAR PRIVACY BOUNDARIES

Local at heart.
Connected by choice.

Local inference uses loopback-only Ollama. Chat, memory and secrets are encrypted on your device. This does not protect against someone with access to your running account.

  • Search: public search providers receive the current question. Avoid secrets in search-enabled requests.
  • Gemini: receives only consented Learning Lab exchanges, never ordinary chats, profile, files or personal memory. Quotas and provider policies apply.
  • Telegram: messages pass through Telegram; one authorized private user is allowed. Personal memory sharing is opt-in.
  • Offline: downloaded local models and saved references work offline. Search, Telegram, Gemini, downloads and updates need internet.
